## 📂 Featured Sub-Projects

### 1. AI-Assisted Computer Repair Shop Management System
- **Path:** `repair-system.html`
- **Description:** A robust, browser-based management system for tracking computer repair tickets. It features real-time cloud database synchronization using Supabase and integrates an AI-assisted diagnostic logic engine to recommend troubleshooting steps based on user-reported symptoms.
- **Key Features:** Real-time CRUD operations, search filtering, dynamic UI status indicators, and AI diagnostic simulation.

### 2. Online Store Sales & Performance Analysis
- **Description:** A comprehensive data analysis case study (satisfying Rubric Step 13) built in Microsoft Excel. It processes raw e-commerce sales data to visualize transaction trends, evaluate discount inefficiencies, and provide evidence-based recommendations on customer retention strategies.
- **Key Features:** Data cleansing, categorical pivoting, performance dashboards, and analytical reporting.

### 3. Interactive Subnetting Calculator
- **Description:** A web-accessible networking utility app that calculates IP subnets, CIDR notations, and subnet masks, providing a live demonstration of core networking concepts.
