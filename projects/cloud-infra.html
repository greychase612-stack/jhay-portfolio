Structured Cabling & Rack Dressing

Cat6 UTP cables run inside cable raceways, bundled with Velcro cable wraps, and terminated into a 24-Port RJ45 Patch Panel using TIA/EIA T568B color pinouts. Certified with zero wiremap transpositions or open pairs.

802.1Q Department Isolation

Switch ports are grouped into dedicated VLANs (HR, Staff, Guest). Isolates broadcast noise and enforces firewall ACLs so visiting guests on Wi-Fi cannot scan, ping, or access internal company servers or confidential shared drives.

Centralized Windows Server Services

Windows Server 2022 domain controller (`corp.local`) centralizes user authentication (AD DS), dynamically provisions IP configurations via DHCP scopes, handles internal DNS resolution, and secures shared folders using NTFS permissions.
