// Smart Automatic Tollgate System with Arduino Uno // Author: Jhay Castro - BSIT Network & Systems Engineering #include <Servo.h> const int trigPin = 9; // HC-SR04 Trigger Pin const int echoPin = 10; // HC-SR04 Echo Pin const int servoPin = 11; // SG90 Servo PWM Pin Servo gateServo; long duration; int distance; const int TRIGGER_DISTANCE = 10; // Vehicle detected at < 10 cm void setup() { Serial.begin(9600); pinMode(trigPin, OUTPUT); pinMode(echoPin, INPUT); gateServo.attach(servoPin); gateServo.write(0); // Initial Position: Gate Closed (0 degrees) Serial.println(F("[SYSTEM INITIALIZED] Automatic Tollgate Online")); } void loop() { // 1. Clear trigger pin digitalWrite(trigPin, LOW); delayMicroseconds(2); // 2. Emit 10 microsecond ultrasonic burst digitalWrite(trigPin, HIGH); delayMicroseconds(10); digitalWrite(trigPin, LOW); // 3. Measure echo return duration in microseconds duration = pulseIn(echoPin, HIGH); // 4. Calculate distance in centimeters (Speed of sound = 0.0343 cm/us) distance = duration * 0.0343 / 2; // 5. Telemetry streaming Serial.print(F("Distance: ")); Serial.print(distance); Serial.print(F(" cm | Gate: ")); // 6. Access Control Logic if (distance > 0 && distance <= TRIGGER_DISTANCE) { Serial.println(F("[OPEN] - Vehicle detected. Lifting barrier...")); gateServo.write(90); // Open gate to 90 degrees delay(3000); // Vehicle transit safety delay } else { Serial.println(F("[CLOSED] - Scanning roadway...")); gateServo.write(0); // Keep barrier down } delay(100); // Polling interval }

Ultrasonic Echolocation Principles & Mathematics

The HC-SR04 operates on acoustic echolocation similar to bat navigation. The transmitter emits an 8-cycle sonic burst at 40 kHz.

Mathematical Formula: Distance (cm) = (Time Duration in µs × Speed of Sound) ÷ 2 Where: • Speed of Sound in Dry Air at 20°C = 343 m/s = 0.0343 cm/µs • Division by 2 accounts for the sound wave's round trip: (Transmitter → Vehicle → Receiver) Example Calculation: • Echo duration measured: 580 µs • Distance = (580 × 0.0343) ÷ 2 = 9.95 cm • 9.95 cm < 10 cm → TRIGGER THRESHOLD MET → OPEN SERVO

Hardware Bill of Materials & Electrical Characteristics

Component architecture detailing operational voltages, current consumption, and signal characteristics for the automated barrier gate.

Microcontroller Timing & Interrupts

The ATmega328P handles microsecond timer captures via `pulseIn()`. Precision timing ensures that ambient noise and reflection echoes do not trigger accidental gate opening.

Acoustic Echolocation Sensing

Dual piezoelectric transducers generate 40 kHz ultrasound. Works reliably regardless of vehicle color, paint reflectivity, or ambient lighting conditions that confuse optical cameras.

PWM Motor Actuation & Gearbox

The SG90 servo utilizes a 50 Hz PWM control signal (1ms to 2ms pulse width). Operates the boom barrier arm with smooth mechanical acceleration, minimizing mechanical stress on the physical pivot.
